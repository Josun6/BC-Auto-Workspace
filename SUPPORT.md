# Support / 用户支持

## English

BC Auto Workspace is independently maintained by Jovi Sun.

Please use **GitHub Issues** for reproducible bug reports, compatibility
feedback, and feature suggestions. When reporting, include the BC version
(Online/On-premises), the relevant Page ID if appropriate, the behavior
you expected, and the behavior you observed.

**Do not share** tenant identifiers, real BC addresses, passwords,
tokens, customer/employee details, orders, or confidential screenshots
in public issues.

Support is best-effort. The free public-beta release includes no
guaranteed response time, 24/7 support, enterprise SLA, or individually
promised customizations.

The extension is not an official Microsoft support channel.

## 简体中文

BC Auto Workspace 由 Jovi Sun 独立维护。

欢迎使用 **GitHub Issues** 报告可复现的问题、BC 兼容性问题及功能建议。
建议说明 BC 版本（Online / On-Premises）、必要时提供 Page ID、
预期行为及实际行为。

**请勿在公开 Issues 中发布**真实租户标识、BC 地址、密码、Token、
客户或员工资料、订单信息以及包含业务敏感信息的截图。

当前免费 Public Beta 以个人精力尽力维护，不承诺固定响应时间、
7×24 小时支持、企业 SLA 或针对单个客户的定制开发。

本项目不是微软官方技术支持渠道。
