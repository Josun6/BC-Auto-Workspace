# Release Notes / 更新记录

## v2.10.1 — Public Beta

### English

- Full-featured free public-beta distribution.
- All 32 built-in Page ID rules and custom Page IDs available.
- Retains Auto View, Auto maximize, Hide FactBoxes, page auto-detection,
  and the independent master ON/OFF switch.
- No license server, payment method, free-tier quota, or trial expiry.
- Includes release information announcing the intended first-year free period.
- This GitHub repository distributes **documentation only**, not code.

**Testing:** 169 automated and synthetic-browser checks were previously
reported for this build. They do **not** constitute a full acceptance
test against live Business Central customer environments.
