# BC Auto Workspace — Product Introduction (English)

**BC Auto Workspace** is an independent Microsoft Edge extension for
Microsoft Dynamics 365 Business Central users.

### Work with less repetitive clicking

- **Auto View:** Safely attempt to switch eligible existing Cards and
  Documents to View mode.
- **Auto maximize:** Expand the workspace using supported BC interface
  controls.
- **Hide FactBoxes:** Collapse the right-side FactBox area when supported.
- **32 built-in rules and unlimited custom Page IDs:** Choose how the
  extension behaves on the pages you work with.
- **Automatic detection and master switch:** Works with supported
  List-to-Card and authorized frame contexts; pause at any time.

### Free public beta

All existing features are planned to be free during the first 12 months
after the initial public release on Microsoft Edge Add-ons. No account,
payment method, trial application, or license key is required. The
current build has no automatic expiration.

Future optional paid features or enterprise services may be considered
after the first year, but nothing has been decided.

### Privacy and safety

The extension stores settings locally and operates only on authorized
BC websites. It has no developer-operated analytics or license server
in the current free release. It is designed not to auto-save, post,
delete or discard unsaved BC changes.

It is **not an access-control system** and does not replace
Business Central permissions.
