# BC Auto Workspace — 产品介绍（中文版）

**BC Auto Workspace** 是一款面向 Microsoft Dynamics 365 Business
Central（BC）用户的独立 Microsoft Edge 浏览器扩展。

### 少一些重复点击，多一些工作空间

- **Auto View：** 对符合安全条件的已有 Card 和 Document 页面，
  尝试自动切换到 View 查看模式。
- **Auto maximize：** 利用 BC 原生界面按钮展开宽屏工作区。
- **Hide FactBoxes：** 在能够识别控件的情况下收起右侧 FactBoxes。
- **32 个内置页面规则 + 无限自定义 Page ID：** 自由配置工作页面。
- **自动识别 + 总开关：** 支持兼容的 List → Card、授权 iframe 场景，
  并能随时暂停自动操作。

计划自插件首次在微软 Edge Add-ons 商店公开上架起，连续 12 个月
免费开放全部现有功能。无需注册、信用卡、试用申请或 License Key。
当前版本不存在一年后自动失效的机制。

一年后会根据真实维护投入和用户需求评估可选收费功能、企业服务，
目前没有确定的付费计划。

### 隐私和操作安全

插件只在用户授权的 BC 网站运行，配置保存在浏览器本地。
当前免费版不包含开发者分析服务和在线 License 服务，不向开发者
发送 ERP 业务记录。

设计上不会自动保存、过账、删除业务记录，或绕过未保存修改确认。
View 模式不代替 BC 后台权限。
